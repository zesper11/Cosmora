#  Cosmora

> **Become whoever you want to be.**

Cosmora is a modern full-stack costume marketplace where users can discover costumes inspired by movies, anime, superheroes, fantasy, horror, and more.

## 🚀 Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **API:** REST API
- **Styling:** CSS

##  Features

- Browse and search costumes
- Filter and sort products
- View detailed product pages
- Shopping cart
- Wishlist
- User authentication
- Order management
- Admin product management
- Responsive design

##  Purpose

Cosmora is a personal full-stack project built to practice the **MERN stack**, REST APIs, authentication, database management, and modern React development.
